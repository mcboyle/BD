# v3.66.848: lxml backs the ARIA audit (bulk_downloader/accessibility.py:185),
# XPath selector evaluation (selector_playground.py:56) and the synthetic
# selector check (synthetic_tests.py:96). All three fail open when it is
# absent -- the audit returns a single "Install lxml to run ARIA audit"
# finding, XPath selectors return an error string, and the synthetic check
# returns {"ok": false, "error": "lxml not installed"} -- so a missing lxml
# degrades silently, exactly as the beautifulsoup4 note above describes.
# It was never declared here, which is why `pip check` reported clean while
# tests/test_v3_43_80_modules.py's TestAccessibility and TestSynthetic failed
# on a fresh container: pip cannot see a requirement that was never written
# down.
# NOT pure Python: lxml is a C extension over libxml2. It ships manylinux,
# macOS and Windows wheels, so the common installs need no toolchain, but a
# platform without a wheel will need libxml2/libxslt headers to build.
lxml>=5.0,<7.0

# v3.66.848: cssselect translates CSS selectors to XPath. Two importers, both
# fail-open, both from the same AST walk:
#   bulk_downloader/selector_playground.py:67 -- sets _HAS_CSSSELECT, which
#     is_available() reports to the operator verbatim. Without it the
#     playground falls back to _css_to_xpath_simple(), a hand-rolled
#     translator for "the common cases the operator actually types" (tag,
#     .class, #id and simple combinations); anything richer stops matching.
#   audit_templates.py:26 -- sets _have_cssselect. check_selector() then skips
#     the cssselect.parse() probe entirely and returns None, so the deep
#     template audit reports every syntactically-INVALID CSS selector as
#     valid. That is the CLAUDE.md section 0 shape: a check whose denominator
#     no longer contains its subject, reporting OK.
# It is also the reason declaring lxml alone is not enough. lxml's
# element.cssselect() is implemented by cssselect and raises ImportError
# without it -- MEASURED here before installing: "cssselect does not seem to
# be installed". That is the PRIMARY path at synthetic_tests.py:96, so a
# cssselect-less install silently routes every synthetic selector through the
# _css_to_xpath fallback. lxml exposes this as its `cssselect` extra rather
# than a hard dependency, so it is not pulled in by the lxml pin above and
# must be declared here.
# Floor 1.2 (2022-10-27, the first py3-only release); current is 1.5.0
# (2026-07-27) and installs into venv as a pure-Python wheel, ~20KB, no build
# step. Ceiling at the next major, matching the neighbours.
cssselect>=1.2,<2.0
