## The rules (a cut that breaks one is not a pure motion)

1. **url_map identity.** `(rule, methods, bare-name)` snapshot byte-identical
   before/after (`tests/test_route_map_invariant.py`). The prime gate.
2. **Lazy state access.** A state-touching view reaches `s_cfg`/`runners`/etc. via
   `from bulk_downloader.app import s_cfg` **inside the function body** — never a 2nd
   copy, never a module-top import (would create a cycle; see CROSS_MONOLITH graph).
3. **Blueprints never top-import `app`** and never register an app-wide hook
   (before_request/after_request/errorhandler). The 9 existing blueprints register none.
4. **Full `/api/...` path in the decorator** (no `url_prefix`); **blueprint names
   unique** (avoid the 9 taken: vpn_api, widgets_api, captcha_relay_api, live_recorder,
   cockpit, cockpit_home, template_manager_ui, data_layer, report_center, settings_center,
   framework, fleet). `api/vpn` → `app_egress` (not `app_vpn_api`); `template*` →
   `app_templates` (not `app_template_manager_ui`).
5. **Resource cohesion.** A path served by two handlers (15 such clusters, e.g.
   `/api/sites/<sid>` = GET/PUT/DELETE + delete) must land in ONE blueprint. The
   `app_decomp_map.py` split-risk check confirms none is fractured.
6. **Re-export the test-imported names** that move so `from bulk_downloader.app import X`
   still resolves: `_pairing_tokens`, `_m2_site_drain_eta` (the rest stay). No view
   function is imported by name in tests — only helpers.
7. **7 release guards byte-identical** — none of `app.py`, `app_common`, or the new
   blueprint is a guard (the guards contain 0 routes). Confirm; declare nothing.

## Standard blueprint module skeleton

```python
from flask import Blueprint, request, jsonify   # + Response/send_file/stream_with_context as the views need
from .db import ...            # leaf modules the views call, imported directly (NOT from .app)
from .app_common import _check_csrf
<domain>_bp = Blueprint("<domain>", __name__)

@<domain>_bp.post("/api/<domain>/...")
def api_...():
    _check_csrf()
    from bulk_downloader.app import s_cfg, runners   # LAZY, in-body, only if state-touching
    ...

def register_routes(app):
    before = len(list(app.url_map.iter_rules()))
    app.register_blueprint(<domain>_bp)
    return len(list(app.url_map.iter_rules())) - before
```

Registration block (~app.py L18731) — fail-open soft import:
```python
try:
    from . import app_<domain>
    app_<domain>.register_routes(app)
except Exception as _<domain>_err:
    import sys as _sys
    _sys.stderr.write(f"[app] <domain> routes not registered: {_<domain>_err}\n")
```
(A silently-failed registration drops routes → the route-map invariant catches it.)
